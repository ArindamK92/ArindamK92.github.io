# Arindam Khanda Personal Website

This is a static personal website built from the CV in this folder.

The site is structured so it can be published directly with GitHub Pages.

## Local preview

Open `index.html` in a browser, or serve the folder with any static server.

## GitHub Pages

To publish this site on GitHub:

1. Create a repository under `ArindamK92`.
2. Push this folder to the repository.
3. In the repo settings, enable GitHub Pages from the `master` branch or use the included Actions workflow.
