# Arindam Khanda Personal Website

Static personal academic website for Arindam Khanda.

The public site is intended to be served from the GitHub Pages user repository:

`https://ArindamK92.github.io`

## Files

- `index.html`: homepage, research themes, updates, publications, and contact
- `profile.html`: education, teaching, service, and honors
- `styles.css`: site styling
- `script.js`: reveal animation behavior
- `arindam.jpg`: profile photo

## GitHub Pages

This repository includes `.nojekyll` so GitHub Pages serves the static files directly.
